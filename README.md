# Tugas Rutin 6: Interactive Quiz App

Aplikasi kuis interaktif berbasis web (Single Page Application) yang dibangun dengan HTML5, CSS3, dan Vanilla JavaScript untuk memenuhi Tugas Rutin 6 mata kuliah Pemrograman Web.

## Fitur

- Pengaturan kuis di halaman beranda (pemilihan topik, jumlah soal, batas waktu, dan opsi acak).
- Render soal dinamis menggunakan DOM API (`createElement`, `textContent`) dan Event Delegation.
- Umpan balik visual untuk jawaban benar dan salah.
- Penyimpanan skor tertinggi (High Score) dan tema (Dark/Light) di LocalStorage.
- Navigasi SPA tanpa reload halaman.

## Cara Menjalankan

Buka berkas `index.html` langsung pada peramban web atau gunakan local server:

```bash
python3 -m http.server 8000
```
Akses melalui `http://localhost:8000`.
